Doors
=====
This is a prototype of a puzzle game.


How to run
==========
In order to run it, you must install python arcade library.

```
$ python3 -m venv .venv
$ source ./venv/bin/activate
(.venv) $ pip install arcade==3.3.3
(.venv) $ python3 doors.py
```
